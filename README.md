# Basic Projects

Small console projects in C++ and Python.

## 1. Student Management System (C++)
Add, view, search, update and delete student records. Data is saved in `students.txt` using file handling.

```
g++ -std=c++17 student_management.cpp -o student_management
./student_management
```

## 2. Tic-Tac-Toe Game (C++)
Two-player console game with win/draw detection, input validation and a play-again option.

```
g++ -std=c++17 tic_tac_toe.cpp -o tic_tac_toe
./tic_tac_toe
```

## 3. Expense Tracker (Python)
Record daily expenses by category and see monthly totals. Data is saved in `expenses.csv`.

```
python3 expense_tracker.py
```
